# AS Productions

Landing page for **AS Productions**, an end-to-end event production and execution company delivering technology events, conferences, hackathons and corporate experiences across India.

Live domain: [asproductions.in](https://asproductions.in)

## Stack

Plain HTML/CSS/JS, no build step, no dependencies. Fonts are loaded from Google Fonts (Fraunces + Space Mono + Inter).

```
index.html            → markup / content
styles.css             → white/yellow/black poster theme, neo-brutalist hard shadows
script.js              → scroll reveals, magnetic buttons, polaroid tilt, marquees, nav
assets/logo.png         → source logo, as supplied
assets/logo-icon.png     → tight-cropped icon mark, for light/white backgrounds (nav)
assets/logo-icon-light.png → same mark, navy swapped for white, for dark backgrounds (footer)
assets/logo-full.png     → icon + "PRODUCTIONS" wordmark, tight-cropped, used as og:image
assets/favicon-*.png     → favicon + apple-touch-icon, generated from the icon mark
assets/placeholders/   → dummy client-logo marks (SVG, self-contained)
CNAME                  → custom domain for GitHub Pages (asproductions.in)
```

The real logo is only usable as-is on a light background; its navy shape nearly disappears
on black. `logo-icon-light.png` is a recolor (navy to white, generated by nearest-color pixel
classification against the two source colors) used everywhere the mark sits on the black
footer. If the logo is redesigned, regenerate it the same way rather than hand-editing pixels.

**Images and video right now are dummy placeholders**, not final assets:
- The showreel embed below the hero points at a public-domain YouTube video (Big Buck Bunny) as a stand-in for the real highlight reel, swap the `src` in `#showreel` for a real AS Productions video.
- Photos (work panels, gallery strip) load from **Wikimedia Commons**, picked to roughly match each caption (conference audience, hackathon/coding, exhibition hall, stage lighting, registration desk, etc.) instead of random stock imagery. They're freely licensed (search `commons.wikimedia.org` in `index.html` to find every instance) but still **someone else's real event photography**, replace with AS Productions' own photos before public launch, both for brand accuracy and to drop any lingering attribution obligation.
- Testimonial avatars are generic silhouette icons (`assets/placeholders/avatar-0*.svg`), deliberately *not* photos of real people, swap for real client headshots once you have permission to use them.
- Client logos in `assets/placeholders/logo-0*.svg` are invented abstract marks (no real brand names/logos), purely to show the grid's grayscale-to-color hover treatment. Replace the files (or the `src` paths) with real partner logos once confirmed.

All of the above require internet access to load (Commons + YouTube + Google Fonts), the page won't render fully offline until real assets replace them.

## Run locally

Just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

### Option A: GitHub Pages (repo already includes `CNAME`)

1. Repo Settings → Pages → Deploy from branch → `main` / root.
2. In your DNS provider for `asproductions.in`, add:
   - `A` records for the apex domain pointing to GitHub Pages IPs:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - (optional) `CNAME` record for `www` → `<your-github-username>.github.io`
3. Wait for DNS to propagate, then enable **Enforce HTTPS** in Pages settings.

### Option B: Vercel / Netlify

Import the repo as a static site (no build command, publish directory = `/`), then attach `asproductions.in` in the project's domain settings and follow their DNS instructions.
